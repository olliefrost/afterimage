# Inspiration

Reference points for look and feel. These were studied for mood and ideas only; nothing from them is used in the game. The original reference images are not included in this repository.

| Source | What we took from it |
| --- | --- |
| ARK: Survival Evolved | A metal gem-like implant set into the arm. The idea for the relic tech that records afterimages: worn on the body, half-broken, mixed with nature. |
| Portal 2 | Abandoned test chambers taken over by plants: clean panels next to rot and greenery, with small cyan lights and a red button as the only bright accents. Our setting, and keeping interactables readable against a busy background. |
| Half-Life series | Outdoor industrial compounds at dusk: raised walkways, stacked rust-orange blocks, stormy skies. Reference for the "outside" levels (not built). |
| Horizon Zero Dawn | Huge dark machine halls with cold blue indicator lights and a few orange warning lamps. Reference for deep-lab interiors: dark base colours with small light points that guide the eye. |
| AER: Memories of Old | A character with no drawn eyes or mouth, just flat shaded planes. Reference for keeping the player and clones' faces blank and anonymous, which also reads cleanly at low pixel resolution. |
| Soul Knight style pixel art | HD pixel-art sprites with readable silhouettes and bright effect trails. Reference for sprite detail level. |
| Generic 2D sprite sheets | Planning which animations the player and clones need (idle, walk, jump, hurt) and roughly how many frames each takes. |
