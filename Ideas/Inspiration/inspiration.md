# Inspiration

Reference material for look and feel. Inspiration only: never copy these assets into the game (see `CLAUDE.md`, Rules and limits).

## Contents

| File | Source | What to take from it |
| --- | --- | --- |
| [ark_survival_implant.jpg](ark_survival_implant.jpg) | ARK: Survival Evolved (screenshot) | A metal gem-like implant set into the player's forearm. Idea for the relic tech that records afterimages: worn on the body, half-broken, mixed with nature. |
| [soul_knight_deviant_art.jpg](soul_knight_deviant_art.jpg) | Soul Knight style character sheet, fan art by "Светлана" on DeviantArt | HD pixel-art character sprites in dynamic action poses with bright effect trails (slashes, bolts, magic). Reference for the sprite detail level, readable silhouettes and attack VFX we want for the player, clones and enemies. |
| [overgrown_chamber_portal.jpg](overgrown_chamber_portal.jpg) | Portal 2 (screenshot) | An abandoned test chamber taken over by plants: vines hanging from the ceiling, grass and moss growing through broken floor panels, collapsed wooden beams. Clean white panels and glass sit next to rot and greenery, with small cyan signage lights and a red button as the only bright accents. Reference for our setting and for keeping interactables readable against a busy, overgrown background. |

## Adding to this folder

Put the file in `Ideas/Inspiration/` and add a row to the table above: file link, where it came from, and what we want to take from it.
