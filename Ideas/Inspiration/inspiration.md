# Inspiration

Reference material for look and feel. Inspiration only: never copy these assets into the game (see `CLAUDE.md`, Rules and limits).

## Contents

| File | Source | What to take from it |
| --- | --- | --- |
| [ark_survival_implant.jpg](ark_survival_implant.jpg) | ARK: Survival Evolved (screenshot) | A metal gem-like implant set into the arm. Idea for the relic tech that records afterimages: worn on the body, half-broken, mixed with nature. |
| [soul_knight_deviant_art.jpg](soul_knight_deviant_art.jpg) | Soul Knight style character sheet, fan art by "Светлана" on DeviantArt | HD pixel-art character sprites in dynamic action poses with bright effect trails (slashes, bolts, magic). Reference for the sprite detail level, readable silhouettes and attack VFX we want for the player, clones and enemies. |
| [overgrown_chamber_portal.jpg](overgrown_chamber_portal.jpg) | Portal 2 (screenshot) | An abandoned test chamber taken over by plants: vines hanging from the ceiling, grass and moss growing through broken floor panels, collapsed wooden beams. Clean white panels and glass sit next to rot and greenery, with small cyan signage lights and a red button as the only bright accents. Reference for our setting and for keeping interactables readable against a busy, overgrown background. |
| [half_life_map.jpg](half_life_map.jpg) | Half-Life series map (screenshot) | An outdoor industrial compound at dusk: cooling tower, chimney, stacked rust-orange blocks, raised walkways and an abandoned truck under a stormy orange sky. Reference for the "outside" levels?|
| [frozen_machine_hall.jpg](frozen_machine_hall.jpg) | Horizon Zero Dawn (inside of a cauldron) | A huge dark machine hall with towering server-like columns, cold blue indicator lights, a few orange warning lamps and snow drifting across the floor. Reference for deep-lab interiors: dark, cold base colours with small light points that guide the eye, and dead tech taken over by nature (here snow, not plants). |
| [pixel_character_animation_sheet.jpg](pixel_character_animation_sheet.jpg) | Unknown pixel-art asset sheet | A small side-view pixel character with Idle, Walk, Run, Push, Jump and Hurt rows (just a placeholder for an example sprite sheet). Reference for the animation set and frame counts we need (Push for movable objects) and for a simple, readable hit flash. Our game is isometric, so we need directional versions. |
| [aer_character.jpg](aer_character.jpg) | AER: Memories of Old (cover art) | The character has no drawn eyes or mouth, just flat shaded planes. Reference for keeping our player and clones' faces blank and anonymous, which also reads cleanly at low pixel resolution. |
| [spritesheet_example.png](spritesheet_example.png) | Unknown stick-figure animation sheet | Ten numbered animation rows (Idle, Walk, Run, Jump, Dash/Roll, Punch, Kick, Sword Slash, Hurt, Death) with frame counts per row. Reference for planning which animations the player and clones need and roughly how many frames each takes; only Idle, Walk and an interact pose are needed for the Must have list. |

## Adding to this folder

Put the file in `Ideas/Inspiration/` and add a row to the table above: file link, where it came from, and what we want to take from it.
