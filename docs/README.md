# Afterimage documentation

Design documents for *Afterimage*, an isometric pixel-art puzzle game made in 24 hours for the University of Bristol Game Jam 2026 (theme: *Time*). For how to play and run it, see the [project README](../README.md).

## Design

| Document | What it covers |
| --- | --- |
| [Game design](game-design.md) | The concept, core mechanic, controls, level list, art direction and outcome |
| [Story and characters](story.md) | Backstory, premise, intro and the player character |
| [UI and clone slots](ui.md) | The HUD, clone slot rules, chamber map, title screen and menus |
| [Audio](audio.md) | Tone, the sound and music plan, and how audio is wired in |
| [Inspiration](inspiration.md) | The games and art that shaped the look |
